# ไฟล์ดีไซน์ต้นฉบับ

`Data Finance Consulting Website.zip` คือไฟล์ที่ export มาจาก Claude Design
ใช้ **อ้างอิงอย่างเดียว** — เปิดในเบราว์เซอร์ตรง ๆ ไม่ได้ เพราะใช้ template
เฉพาะของ Claude Design (`<sc-if>`, `{{ }}`, `<image-slot>`, `<x-import>`)

เว็บจริงคือไฟล์ .html ที่โฟลเดอร์แม่ ซึ่งแปลงมาจากดีไซน์นี้แล้วครบทุกหน้า
ห้ามแก้ไฟล์ในโฟลเดอร์นี้
